# 运行环境要求

本文档说明项目运行时的资源要求、服务端口、性能指标与健康检查。

## 服务端口

| 服务 | 默认端口 | 说明 |
|------|----------|------|
| musicServer | 8080 | 后端 API 服务 |
| musicAdmin | 8089 | 管理端前端（开发） |
| musicClient | 8090 | 客户端前端（开发） |
| MySQL | 3306 | 关系型数据库 |
| Redis | 6379 | 缓存与会话 |
| MinIO | 9000 | 对象存储服务 |

## 硬件资源建议

### 生产环境（最小配置）

| 服务 | CPU | 内存 | 磁盘 |
|------|-----|------|------|
| musicServer | 2 核 | 4 GB | 20 GB |
| MySQL | 2 核 | 4 GB | 50 GB SSD |
| Redis | 1 核 | 2 GB | 10 GB |
| MinIO | 2 核 | 4 GB | 100 GB |

### 开发环境

- CPU：2 核及以上
- 内存：8 GB 及以上
- 磁盘：20 GB 可用空间

## 性能指标

### 页面加载

- 管理端页面首次加载时间 ≤ 2 秒
- 客户端页面首次加载时间 ≤ 2 秒
- 推荐启用 CDN 与资源压缩

### 接口响应

- 普通查询接口 P99 ≤ 500ms
- 文件上传接口视网络与文件大小而定
- AI 对话接口响应受模型与网络影响，建议配置超时与降级

### 并发能力

- 后端服务并发能力取决于 JVM 内存、数据库连接池与 Redis 配置
- 默认 Druid 连接池与 Redis 连接数需根据实际负载调整

## 健康检查

| 端点 | 说明 |
|------|------|
| `GET /chat/health` | AI 聊天服务健康状态 |
| `GET /admin/rag/health` | RAG 向量检索健康状态 |
| Spring Boot Actuator | 如需可引入 `spring-boot-starter-actuator` |

## 日志要求

- 后端日志统一输出到文件，建议按日期滚动
- 关键路径日志：登录、登出、敏感操作、AI 调用
- 生产环境关闭 MyBatis SQL 控制台输出
- 前端错误通过 Sentry 或类似服务收集（可选）

## 监控告警

建议对以下指标进行监控：

- JVM 内存与 GC 情况
- CPU 与磁盘使用率
- MySQL 慢查询
- Redis 连接数与命中率
- MinIO 存储空间
- AI 接口可用性与响应时间

## 备份策略

- MySQL：每日全量备份 + 增量备份
- Redis：开启 RDB/AOF 持久化
- MinIO：启用版本控制或异地备份
