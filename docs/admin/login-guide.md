# 管理端登录指南

本文档说明音乐管理后台的登录流程、页面布局与常见问题处理。

## 访问地址

- 本地开发：`http://localhost:8089`
- 生产环境：由运维部署的域名决定

## 登录页面

登录页位于 `src/views/login/index.vue`，采用 Matrix 设计风格：

- 深色背景，左侧为 Lithos 地质主题视觉区
- 右侧为登录卡片，包含用户名、密码输入框
- 支持“7 天内免登录”记住我功能
- 表单校验与错误提示机制

## 登录流程

1. 打开管理后台地址
2. 输入管理员用户名与密码
3. 可选：勾选“7 天内免登录”
4. 点击“登录”按钮
5. 前端校验通过后，调用 `/admin/login` 接口
6. 服务端校验成功返回 JWT Token
7. 前端存储 Token 并跳转至首页

## 表单校验规则

| 字段 | 规则 |
|------|------|
| 用户名 | 必填，4-16 位字母/数字/下划线/连字符 |
| 密码 | 必填，8-18 位，至少包含数字、字母、符号中的两种 |

## 安全特性

- 密码使用 BCrypt 加密存储
- Token 有效期 6 小时，同时写入 Redis 支持主动吊销
- 连续失败或 Token 过期时自动跳转登录页
- 页面展示“SYSTEM ONLINE”与“SECURE”状态标识

## 常见问题

| 问题 | 处理方式 |
|------|----------|
| 提示“用户名或密码错误” | 确认大小写、检查账号是否被禁用 |
| 提示“登录已过期” | Token 过期，重新登录；如勾选记住我可延长本地存储 |
| 页面白屏或加载缓慢 | 检查后端服务与网络连接，查看浏览器控制台错误 |
| 无法访问登录页 | 确认服务端口（默认 8089）及 Nginx 代理配置 |
