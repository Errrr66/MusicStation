# 用户管理操作手册

本文档说明音乐管理后台“用户管理”模块的功能与操作流程。

## 模块入口

- 路径：`src/views/user`
- 页面：`index.vue`（列表）、`form/index.vue`（表单）
- 路由：用户管理

## 功能概述

用户管理模块用于维护平台注册用户的基本信息，支持新增、编辑、删除、批量删除与状态控制。

## 列表页面

### 搜索条件

| 条件 | 说明 |
|------|------|
| 用户名 | 按用户名模糊搜索 |
| 手机号码 | 按手机号精确/模糊搜索 |
| 状态 | 启用 / 禁用 |

### 操作按钮

- **搜索**：根据条件刷新列表
- **重置**：清空搜索条件
- **新增用户**：打开新增弹窗
- **批量删除**：选中多项后一键删除

### 表格列

| 列名 | 说明 |
|------|------|
| 用户编号 | 唯一标识 |
| 用户名 | 登录账号 |
| 手机号 | 绑定手机号 |
| 邮箱 | 绑定邮箱 |
| 简介 | 个人简介 |
| 状态 | 启用 / 禁用 |
| 创建时间 | 注册时间 |
| 操作 | 修改、删除 |

### 行级操作

- **修改**：编辑用户信息
- **删除**：删除单个用户（二次确认）

## 新增/编辑表单

### 表单字段

| 字段 | 必填 | 说明 |
|------|------|------|
| 用户编号 | - | 系统自动生成，仅修改时展示且不可编辑 |
| 用户名 | 是 | 4-16 位字母/数字/下划线/连字符 |
| 用户密码 | 是 | 新增时必填，修改时不展示 |
| 邮箱 | 是 | 需符合邮箱格式 |
| 手机号 | 否 | 需符合 11 位手机号格式 |
| 简介 | 否 | 100 字以内 |
| 用户状态 | 否 | 启用 / 禁用（新增时展示） |

## 操作注意事项

1. 删除用户会同时清除其相关数据关联，请谨慎操作
2. 禁用用户后，该账号将无法登录客户端
3. 批量删除前请确认已选数据，避免误删
4. 密码在新增时由管理员设置，系统会自动使用 BCrypt 加密
