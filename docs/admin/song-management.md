# 歌曲管理操作手册

本文档说明音乐管理后台“歌曲管理”模块的功能与操作流程。

## 模块入口

- 路径：`src/views/song`
- 页面：
  - `index.vue`：歌曲列表
  - `form/index.vue`：歌曲表单
  - `form/upload.vue`：音频上传
  - `form/preview.vue`：音频预览
  - `tree.vue`：歌手树形筛选
- 路由：歌曲管理

## 功能概述

歌曲管理模块用于维护平台歌曲资源，支持按歌手筛选、新增、编辑、删除、上传封面/音频与在线预览。

## 列表页面

### 左侧歌手树

- 操作歌曲前需先在左侧选择歌手
- 点击歌手节点后，右侧表格展示该歌手下的歌曲

### 搜索条件

| 条件 | 说明 |
|------|------|
| 歌名 | 按歌曲名称模糊搜索 |
| 专辑 | 按专辑名称模糊搜索 |

### 操作按钮

- **搜索**：刷新当前歌手下的歌曲列表
- **重置**：清空搜索条件
- **新增歌曲**：打开新增弹窗
- **批量删除**：选中多项后一键删除

### 表格列

| 列名 | 说明 |
|------|------|
| 歌曲编号 | 唯一标识 |
| 歌名 | 歌曲名称 |
| 歌手 | 所属歌手 |
| 专辑 | 专辑名称 |
| 发行日期 | 歌曲发行时间 |
| 曲风 | 歌曲风格标签 |
| 操作 | 修改、删除、更多操作 |

### 行级操作

- **修改**：编辑歌曲信息
- **删除**：删除单首歌曲（二次确认）
- **更多**：上传封面、上传音频、预览音频

## 新增/编辑表单

### 表单字段

| 字段 | 必填 | 说明 |
|------|------|------|
| 歌手编号 | - | 由左侧选择的歌手自动填充，不可编辑 |
| 歌曲编号 | - | 系统自动生成，仅修改时展示 |
| 歌名 | 是 | 歌曲名称 |
| 专辑 | 是 | 专辑名称 |
| 发行日期 | 是 | 日期选择器 |
| 曲风 | 否 | 多选，如华语流行、摇滚、电子等 |

### 曲风选项

节奏布鲁斯、欧美流行、华语流行、粤语流行、国风流行、韩国流行、日本流行、嘻哈说唱、非洲节拍、原声带、轻音乐、摇滚、朋克、电子、国风、乡村、古典。

## 资源上传

### 上传封面

- 支持常见图片格式（JPG、PNG 等）
- 上传成功后封面 URL 写入歌曲记录

### 上传音频

- 支持 MP3、FLAC 等音频格式
- 上传成功后提取歌曲时长并写入记录
- 支持后续通过 AI 接口自动补全歌词

### 预览音频

- 在列表中点击“预览音频”可在线试听
- 预览弹窗展示歌曲名称与音频播放器

## 操作注意事项

1. 必须先选择歌手才能新增歌曲
2. 删除歌曲会同时移除其与歌单的绑定关系
3. 音频文件较大时请耐心等待上传完成
4. 建议在上传音频后检查时长与歌词是否自动填充
