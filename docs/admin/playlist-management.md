# 歌单管理操作手册

本文档说明音乐管理后台“歌单管理”模块的功能与操作流程。

## 模块入口

- 路径：`src/views/playlist`
- 页面：
  - `index.vue`：歌单列表
  - `form/index.vue`：歌单表单
- 路由：歌单管理

## 功能概述

歌单管理模块用于维护平台推荐歌单，支持新增、编辑、删除、批量删除与封面上传。

## 列表页面

### 搜索条件

| 条件 | 说明 |
|------|------|
| 歌单 | 按歌单标题模糊搜索 |
| 风格 | 按歌单风格筛选 |

### 风格选项

节奏布鲁斯、欧美流行、华语流行、粤语流行、国风流行、韩语流行、日本流行、嘻哈说唱、非洲节拍、原声带、轻音乐、摇滚、朋克、电子、国风、乡村、古典。

### 操作按钮

- **搜索**：根据条件刷新列表
- **重置**：清空搜索条件
- **新增歌单**：打开新增弹窗
- **批量删除**：选中多项后一键删除

### 表格列

| 列名 | 说明 |
|------|------|
| 歌单编号 | 唯一标识 |
| 歌单标题 | 歌单名称 |
| 风格 | 歌单风格 |
| 简介 | 歌单描述 |
| 操作 | 修改、删除、上传封面 |

### 行级操作

- **修改**：编辑歌单信息
- **删除**：删除单个歌单（二次确认）
- **上传封面**：上传歌单封面图片

## 新增/编辑表单

### 表单字段

| 字段 | 必填 | 说明 |
|------|------|------|
| 歌单编号 | - | 系统自动生成，仅修改时展示且不可编辑 |
| 歌单 | 是 | 歌单标题 |
| 风格 | 否 | 单选风格 |
| 简介 | 否 | 歌单描述，支持多行文本 |

## 操作注意事项

1. 歌单删除后，客户端将无法再访问该歌单
2. 封面图片建议使用 1:1 比例，大小不超过 2MB
3. 歌单风格影响客户端的分类展示与推荐算法
4. 如需向歌单中添加歌曲，需通过歌单-歌曲绑定功能维护（如已开发）
