# 艺人管理操作手册

本文档说明音乐管理后台“艺人管理”模块的功能与操作流程。

## 模块入口

- 路径：`src/views/artist`
- 页面：
  - `index.vue`：艺人列表
  - `form/index.vue`：艺人表单
- 路由：艺人管理

## 功能概述

艺人管理模块用于维护平台歌手/艺人信息，支持新增、编辑、删除、批量删除与头像上传。

## 列表页面

### 搜索条件

| 条件 | 说明 |
|------|------|
| 歌手 | 按歌手名称模糊搜索 |
| 国籍 | 按国籍/地区模糊搜索 |
| 类型 | Male / Female / 组合/乐队 |

### 操作按钮

- **搜索**：根据条件刷新列表
- **重置**：清空搜索条件
- **新增歌手**：打开新增弹窗
- **批量删除**：选中多项后一键删除

### 表格列

| 列名 | 说明 |
|------|------|
| 歌手编号 | 唯一标识 |
| 歌手 | 艺人姓名 |
| 类型 | 性别或组合类型 |
| 生日 | 出生日期 |
| 国籍 | 地区/国籍 |
| 简介 | 艺人介绍 |
| 操作 | 修改、删除、上传头像 |

### 行级操作

- **修改**：编辑艺人信息
- **删除**：删除单个艺人（二次确认）
- **上传头像**：上传艺人头像图片

## 新增/编辑表单

### 表单字段

| 字段 | 必填 | 说明 |
|------|------|------|
| 歌手编号 | - | 系统自动生成，仅修改时展示且不可编辑 |
| 歌手 | 是 | 艺人姓名 |
| 类型 | 否 | Male / Female / 组合/乐队 |
| 生日 | 否 | 日期选择器 |
| 国籍 | 否 | 地区/国籍 |
| 简介 | 否 | 艺人介绍，支持多行文本 |

## 操作注意事项

1. 删除艺人前，请确认其下已无关联歌曲，否则可能导致客户端显示异常
2. 艺人头像建议使用正方形图片，比例 1:1
3. 类型字段影响客户端的歌手分类展示
4. 艺人信息修改后会同步影响歌曲详情页中的歌手展示
