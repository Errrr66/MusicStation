# 轮播图管理操作手册

本文档说明音乐管理后台“轮播图管理”模块的功能与操作流程。

## 模块入口

- 路径：`src/views/banner`
- 页面：
  - `index.vue`：轮播图列表
  - `utils/hook.tsx`：包含上传/编辑弹窗逻辑
- 路由：轮播图管理

## 功能概述

轮播图管理模块用于配置客户端首页轮播展示图，支持上传图片、启用/禁用状态切换、编辑与删除。

## 列表页面

### 搜索条件

| 条件 | 说明 |
|------|------|
| 状态 | 启用 / 禁用 |

### 操作按钮

- **搜索**：根据状态刷新列表
- **重置**：清空搜索条件
- **新增轮播图**：打开图片上传弹窗

### 表格列

| 列名 | 说明 |
|------|------|
| 轮播图编号 | 唯一标识 |
| 轮播图 | 图片预览（点击可放大） |
| 状态 | 启用 / 禁用开关 |
| 操作 | 编辑、删除 |

### 行级操作

- **编辑**：重新上传或替换轮播图
- **删除**：删除单张轮播图（二次确认）

## 新增/编辑流程

1. 点击“新增轮播图”或行级“编辑”
2. 打开图片上传弹窗（内置裁剪组件）
3. 选择本地图片并调整裁剪区域
4. 确认上传后保存到 MinIO 并写入数据库
5. 列表自动刷新

## 状态管理

- 每行轮播图带有 `ElSwitch` 开关
- 切换开关时会弹出二次确认
- 启用状态的轮播图会展示在客户端首页
- 禁用状态的轮播图在客户端不展示

## 图片规范

- 建议尺寸：宽度 1200px 以上，宽高比约 16:6
- 推荐格式：JPG、PNG
- 单张图片大小建议不超过 2MB
- 上传后系统会自动生成访问 URL

## 操作注意事项

1. 至少保留一张启用状态的轮播图，避免客户端首页空白
2. 删除轮播图不会删除 MinIO 中的物理文件，需定期清理
3. 状态切换会实时生效，客户端下次请求时会获取最新列表
4. 批量删除前请确认已选数据
