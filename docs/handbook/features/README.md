# 功能文档总览

本目录按业务能力拆分功能文档，面向研发、测试与产品协作。

## 使用说明

- 每篇功能文档统一采用以下章节模板：
  - 功能边界
  - 用户入口 / 角色
  - 页面与交互（或服务入口）
  - 接口清单（重点）
  - 前置条件
  - 关键流程
  - 配置项（重点）
  - 验证步骤
  - 已知限制与待确认
  - 关联文档
- 文档仅记录已落地能力；未确认内容统一标注“待确认”。
- 新增功能时，请先更新本索引，再补对应专题文档。
