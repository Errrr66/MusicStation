# 用户账号与个人主页

## 功能边界

- 用户登录、会话态维护、个人资料展示。
- 个人主页支持公开访问与登录态个性化字段返回。

## 用户入口 / 角色

- 登录页面与会话恢复。
- 个人主页（本人或他人）。

## 页面与交互

- 未登录可访问公开主页基础信息。
- 登录后可获取关注关系、互关状态等个性化字段。

## 接口清单（重点）

- 登录接口：`/user/login`（前端请求拦截器中显式豁免 token 注入）。
- 社交资料接口：`/social/profile/**`（公开可访问，登录态增强）。

## 前置条件

- 登录接口可用且用户凭据有效。
- 前端用户状态管理可正确持久化 token。

## 关键流程

1. 登录成功后前端缓存 token。
2. 请求拦截器为业务接口附加 `Authorization`。
3. 公开接口允许匿名访问；登录态可注入上下文返回个性化数据。

## 配置项（重点）

- 前端请求拦截器 token 注入策略。
- 后端公开接口匿名访问与登录态解析策略。

## 验证步骤

1. 执行登录，确认 token 存储成功。
2. 未登录访问个人主页，确认公开信息可见。
3. 登录后访问同一主页，确认个性化字段返回正常。

## 已知限制与待确认

- 注册、找回密码与多端登录策略文档待补充。
- 用户资料编辑能力待确认。
