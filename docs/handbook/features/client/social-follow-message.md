# 社交关注与私信

## 功能边界

- 支持关注 / 取关、粉丝与关注关系展示。
- 支持私信会话与消息轮询刷新。

## 用户入口 / 角色

- 个人主页关注按钮。
- 消息中心会话列表与消息面板。
- 使用角色：登录用户。

## 页面与交互

- 个人主页显示 `following` / `mutualFollow` 状态。
- 私信页支持会话切换与消息拉取。
- 刷新链路采用静默策略，降低 UI 闪烁。

## 接口清单（重点）

- 社交资料接口：`/social/profile/**`
- 粉丝列表接口：`/social/followers/**`
- 关注列表接口：`/social/following/**`
- 私信与会话接口：`/social/messages/*`、`/social/conversations`

## 前置条件

- 用户处于登录状态，token 可用。
- 社交接口允许公开访问与登录态增强（按接口策略返回字段）。

## 关键流程

1. 访问他人主页时拉取公开资料。
2. 登录态下附带 token，可返回真实关注关系。
3. 关注/取关成功后前端本地更新状态，再与服务端同步。
4. 消息页通过轮询静默刷新会话与消息。

## 配置项（重点）

- 前端轮询间隔与静默刷新策略（页面实现层）。
- 公开接口鉴权策略（服务端拦截器配置层）。

## 验证步骤

1. 未登录访问他人主页，确认可查看公开资料。
2. 登录后进入同一主页，确认 `following` / `mutualFollow` 正确。
3. 点击关注再点击取关，确认状态与计数更新正常。
4. 打开私信页，确认会话与消息能稳定刷新且不闪屏。

## 已知限制与待确认

- 消息实时性目前依赖轮询；是否升级 WebSocket 待评估。
- 社交通知中心能力待确认。
