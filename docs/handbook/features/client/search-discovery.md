# 搜索、曲库与内容浏览

## 功能边界

- 提供歌曲/歌单等内容检索与浏览。
- 支持从聊天引用或推荐结果跳转到曲库或详情页。

## 用户入口 / 角色

- 入口来源：聊天页面引用卡片、侧边导航、曲库页面。
- 使用角色：普通登录用户、未登录访客（部分公开内容）。

## 页面与路由

- 曲库页面：`/library`（见聊天页引用跳转逻辑）。
- 歌单详情：`/playlist/:id`。

## 接口清单（重点）

- `GET /chat/health`（用于检索能力观测）。
- 其他检索接口：待确认（按系统 API 实际定义补充）。

## 前置条件

- 后端检索相关服务正常可用。
- 前端路由配置包含曲库页与歌单详情页。

## 关键流程

1. 用户输入关键词或通过引用卡片触发跳转。
2. 前端根据类型进入歌单详情或曲库搜索。
3. 用户可进一步播放歌曲、收藏或执行二次筛选。

## 配置项（重点）

- `agent.search.*`（检索行为相关配置，具体项待确认）。
- `agent.rag.*`（聊天检索增强相关）。

## 验证步骤

1. 在聊天页点击歌曲/歌单引用，确认路由跳转正确。
2. 在曲库输入关键词，确认结果列表可见。
3. 点击歌单项，确认可进入对应详情页。

## 已知限制与待确认

- 搜索排序策略细粒度说明待补充。
- 曲库过滤项与分页策略待补充。
