# 变更记录 - 2026-04-06

## 范围

本次交付聚焦 `musicServer` 与 `musicClient` 的 Agent / RAG / 聊天能力。

## 后端

- 在 `AgentRagService` 中新增 RAG 混合检索骨架：
  - 支持 `keyword`、`vector`、`hybrid` 模式。
  - 增加权重评分控制。
  - 记录最近一次检索健康指标。
- 新增 `GET /chat/health`：
  - 暴露 RAG 状态与服务提供方可用性。
  - 返回检索计数与更新时间。
- 优化流式控制器运行时处理：
  - 将无界缓存线程池替换为固定线程池，用于 SSE 任务。
  - 将 `ChatController` 控制台输出替换为结构化日志。
- 移除聊天健康链路中对 NetEase OpenAPI 健康/配置的依赖。
- 在 `SongServiceImpl` 中重命名歌词辅助方法：
  - `fetchLyricFromNetease` -> `fetchLyricFromProvider`
  - 行为保持不变。

## 前端

- 增强 `musicClient/src/pages/chat/index.vue` 聊天体验：
  - 新增健康检查刷新与面板折叠能力。
  - 新增流式状态与时延指标展示。
  - 新增检索命中提示。
- 新增引用卡片点击行为：
  - 歌单引用跳转到歌单详情。
  - 歌曲引用触发播放或降级到曲库搜索。
- 更新 `musicClient/src/api/chat.ts` 的 API 类型：
  - 新增聊天健康检查响应模型。
  - 新增引用类型定义。

## 配置

- 在 `application.yml` 中新增 RAG 配置项：
  - `agent.rag.mode`
  - `agent.rag.keyword-weight`
  - `agent.rag.vector-weight`
- 移除激活配置中的 `netease.openapi.*` 配置块。
