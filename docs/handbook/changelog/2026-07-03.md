## 后端

- 修复 Admin 账户登录失败问题：
  - 在 `musicServer/src/main/java/com/example/music/interceptor/LoginInterceptor.java` 中增加 Redis 异常处理，避免 Redis 不可用时 token 验证直接失败。
- 修复密码正则表达式：
  - 更新 `musicAdmin/src/views/login/utils/rule.ts`，允许密码包含下划线，与注册规则保持一致。
- 修复歌曲详情接口序列化异常：
  - 在 `SongDetailVO` 与 `CommentVO` 上添加 `@JsonIgnoreProperties({"handler", "objectFactory"})`，解决 MyBatis 懒加载代理对象写入 Redis/返回前端时 Jackson 无法序列化的问题。该异常导致 `/song/getSongDetail/{id}` 返回失败，前端评论区显示“暂无歌曲信息”。
