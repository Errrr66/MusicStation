# 变更记录 - 2026-04-18

## 范围

本次交付聚焦 `musicClient` 的语音交互与 Orb 可视化能力。

## 前端

- 升级 `musicClient/src/pages/chat/index.vue` 的双模式交互：
  - 新增 `TTS` 与 `语音` 模式切换。
  - Orb 仅在语音模式展示，避免干扰文本聊天视图。
- 实现实时语音问答链路：
  - 支持用户再次发言时打断当前回复（barge-in）。
  - 通过队列处理后续语音问题，避免请求丢失。
- 接入 Orb 真音量驱动：
  - 输入音量来自麦克风分析器（`getInputVolume`）。
  - 输出音量来自 TTS 播放分析器（`getOutputVolume`）。
- 优化 Orb 状态切换平滑度：
  - 状态驱动颜色切换（`listening`、`thinking`、`talking`）。
  - 平滑处理振幅与状态响应曲线。
- 增强浏览器语音识别生命周期稳定性：
  - 增加安全启停保护，避免重复调用 `start()`。
  - 增加轻量去重与语气词过滤，降低误触发。
- 优化 TTS 播放与可视化兼容性：
  - 优先使用非侵入式流捕获分析。
  - 即使分析器挂载失败也保持可播放。
  - 当 TTS 播放中但无分析数据时提供兜底脉冲。

## 组件

- 增强 `musicClient/src/components/voice/Orb.vue`：
  - 新增 `colorsRef`，支持外部动态颜色控制。
  - 新增音量 / 状态 / 颜色平滑过渡曲线。
  - 保留并强化自动/手动音量模式的边界处理。
