# Markdown 编写规范

本规范定义 `music` 项目的 Markdown 基线格式。

## 1. 标题层级

- 每个文件只允许一个一级标题：`# 标题`。
- 主要章节使用 `##`。
- 子章节使用 `###`。
- 禁止跳级使用标题。

## 2. 日期与版本

- 日期格式统一为 `YYYY-MM-DD`。
- 版本号统一为 `vX.Y.Z`。
- 变更记录需同时包含日期与范围说明。

## 3. 代码块

- 统一使用围栏代码块（fenced code block）。
- 代码块必须标注语言，例如：
  - `bat`：Windows `cmd.exe` 命令
  - `bash`：Shell 命令
  - `json`：接口请求/响应示例
  - `http`：HTTP 报文示例

## 4. 路径与命令

- 路径、命令、标识符统一使用行内代码标记。
- 优先使用仓库相对路径。
- 非必要场景避免写死本机绝对路径。

## 5. 列表与表格

- 无序列表统一使用 `-`。
- 每个列表项只表达一个核心点。
- 仅在需要固定字段对比时使用表格。

## 6. 语言与标点

- 中文文档使用中文标点，表达简洁。
- 英文术语仅保留必要技术名词。
- 术语写法保持一致：`RAG`、`TTS`、`DeepSeek`、`Orb`、`AI Agent`。

## 7. 交叉引用

- 优先使用相对链接（例如 `../operations/ai-agent-runbook.md`）。
- 文档迁移后需立即修正引用路径。
- 新增或删除文档时，必须同步更新 `docs/handbook/README.md`。
