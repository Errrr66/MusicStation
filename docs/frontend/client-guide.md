# 客户端用户指南

本文档说明音乐平台用户客户端（musicClient）的主要页面与功能，面向终端用户与产品经理。

## 项目简介

musicClient 是面向普通用户的音乐播放与发现平台，提供歌曲浏览、歌单推荐、艺人主页、AI 音乐助手、私信社交、个人音乐库等功能。

## 技术栈

- Vue 3 + Vite + TypeScript
- Element Plus UI 组件库
- Pinia 状态管理
- Tailwind CSS 样式框架
- Vue Router 路由管理

## 首页发现

- 展示轮播图推荐
- 展示推荐歌单
- 展示推荐歌曲
- 支持点击歌曲直接播放
- 未登录时展示默认推荐，登录后基于用户行为个性化推荐

## 歌手模块

### 歌手列表

- 分页展示平台所有歌手
- 支持按歌手名称搜索
- 点击歌手卡片进入歌手详情

### 歌手详情

- 展示歌手头像、简介、基本信息
- 展示歌手全部歌曲
- 支持播放歌手歌曲、收藏歌手

## 歌单模块

### 歌单广场

- 展示平台推荐歌单
- 支持按风格筛选
- 支持搜索歌单

### 歌单详情

- 展示歌单封面、标题、简介
- 展示歌单内歌曲列表
- 支持播放全部、收藏歌单、分享歌单

## AI 音乐助手

- 基于 DeepSeek 的音乐问答助手
- 支持文字对话与语音对话
- 可推荐歌曲、歌单、艺人
- 支持将 Agent 生成的歌单保存到个人收藏
- 集成 RAG 检索，可基于平台曲库知识回答
- 提供真流式 SSE 响应（`/chat/agent/stream/v2`）

## 音乐库

- 展示平台全部歌曲
- 支持分页浏览
- 支持按歌曲名搜索
- 可将歌曲加入播放列表或收藏

## 我的喜欢

- 展示用户收藏的歌曲
- 支持取消收藏
- 支持一键播放全部喜欢歌曲

## 私信消息

- 展示用户会话列表
- 支持查看与好友的私信记录
- 支持发送文字私信
- 支持分享歌曲与歌单

## 用户主页

- 展示用户头像、昵称、简介
- 展示用户关注/粉丝数
- 展示用户公开歌单与喜欢
- 支持关注/取消关注

## 综合搜索

- 支持搜索歌曲、歌手、歌单、用户
- 搜索结果分类展示
- 支持点击结果进入详情或播放

## 个人中心

- 修改个人资料
- 修改头像
- 修改密码
- 查看系统设置
- 退出登录/注销账号

## 全局播放器

- 位于页面底部固定位置
- 支持播放/暂停、上一首/下一首
- 支持进度拖动、音量调节
- 支持播放模式切换（顺序/随机/单曲循环）
- 支持展开全屏播放器

## 认证相关

- 登录弹窗支持账号密码登录、注册、重置密码
- 登录后 Token 写入本地存储
- 未登录用户可浏览公开内容，但无法使用收藏、私信、AI 助手等功能
