### [v1.0.2] - 2026-03-10
#### 新增功能
- Shazam 识曲功能集成
- 右侧详情栏（Right Sidebar）实现：
    - 新增 RightAside 组件，采用响应式布局（md 断点控制显隐），支持折叠/展开交互（宽度在 384px ↔ 120px 之间平滑过渡）；
    - 当前播放视图：集成大幅方形专辑封面，高亮显示歌曲标题及艺人名称；
    - 快捷收藏：在当前播放信息区集成「红心」收藏按钮，支持实时鉴权、状态切换，并通过 ElMessage 给出操作反馈；
    - 艺人百科卡片：
        - 实现基于当前播放曲目的艺人信息动态获取机制（监听 currentTrack.artist）；
        - 集成 getAllArtists 与 getArtistDetail 接口，自动拉取艺人头像及简介；
        - 支持点击艺人卡片跳转至艺人详情页（/artist/:id）；
    - 播放队列预览：
        - 新增「下一首」卡片，实时计算并展示队列中待播放的曲目信息；
        - 支持点击卡片直接切换播放下一首曲目（playNext）。

#### 界面与交互
- 深色模式适配：所有组件均支持深色模式（Dark Mode），背景色采用层次化灰度设计（#121212 / #1e1e1e），文本颜色自动反转适配；
- 视觉优化：
    - 引入 Spotify 风格的卡片式排版；
    - 图片资源增加加载兜底方案（Default Cover/Avatar）；
    - 文本区域（如艺人简介）增加行数限制及溢出省略处理；
- 滚动体验：定制化 CSS 滚动条（custom-scrollbar），隐藏原生滚动条并优化滑块视觉效果；
- 交互微效：添加封面悬停播放遮罩、按钮点击波纹反馈及折叠按钮的图标切换动画。

#### 核心逻辑
- 数据清洗：针对后端返回的富文本艺人简介，新增正则过滤器（replace(/<[^>]+>/g, '')）移除 HTML 标签，确保纯文本展示安全且格式整洁；
- 状态管理：重构播放状态监听逻辑，利用 watch 深度监听音轨变化，通过 computed 属性实时计算收藏状态与下一首曲目信息，减少不必要的页面重渲染；
- 异常处理：增强接口调用链的健壮性，为艺人信息获取失败、未登录状态下操作等场景，添加完整的 try-catch 异常捕获及功能降级处理策略。

### 总结
1. 功能层面：核心新增右侧详情栏组件，集成 Shazam 识曲、艺人百科、播放队列预览等实用功能，补充快捷收藏交互；
2. 体验层面：全量适配深色模式，优化视觉排版、滚动样式及交互微效，贴合主流音乐应用设计风格；
3. 性能与稳定性层面：通过数据清洗、状态管理重构及异常捕获，提升数据展示安全性、页面渲染效率及接口调用健壮性。
